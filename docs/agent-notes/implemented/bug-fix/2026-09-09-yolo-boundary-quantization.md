# Agent Note: YOLO 边界框量化容差

Status: implemented

## Problem

检测框允许使用图像边界作为坐标，例如 `xmax=1920` 或 `ymax=1080`。YOLO 检测框序列化为六位小数后，浮点量化可能使还原坐标超出边界约一个像素量化单位，导致合法标注无法转换。

## Decision

检测框编码继续拒绝原始坐标越界的标注。编码后的六位小数坐标在回算检查中按图像宽高分别使用 `dimension * 1e-6` 的量化容差，从而保留合法边界框，同时仍拒绝量化后退化为零宽或零高的框以及原始的明显越界框。

## Alternatives considered

**固定绝对容差。** 该方案不能随图片分辨率和坐标轴变化，可能对较大图片过严或对较小图片过宽，因此不采用。

**移除编码后的回算检查。** 该方案会放弃对序列化结果几何有效性的检查，因此不采用。

## Consequences

边界贴合的检测框可以稳定写入 YOLO 数据集，容差与六位小数的量化精度和图像尺寸一致。量化容差只用于编码后的回算检查；输入标注和解码器的严格边界语义保持不变。

相关回归测试覆盖边界量化通过、明显越界拒绝和量化后零宽框拒绝。
