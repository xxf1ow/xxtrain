# Agent Note: 管理员封存审核与基准数据集治理

Status: proposed

## Problem

基准数据集需要持续吸收普通用户工作区中已经完成标注的数据，但用户不会主动判断数据何时适合提交审核。工作区还可能持续新增图片、修改标注或运行训练；管理员需要在不引入审核快照、局部模型封存或多级权限体系的前提下，获得稳定的审核边界。CVAT 适合查看和修改标注，不适合承担基准数据集的批次目录、封存流程和启停管理。

## Proposal

平台保留普通用户页面和独立管理员入口。管理员入口使用单独的管理密钥保护，不建设多用户管理、管理员账号体系或管理员上传入口。管理员继续可以持有普通用户账号，用普通用户页面上传图片、已有标注并完成工作区标注或训练。

管理员页面包含三个职责明确的区域：

- **工作区管理**：显示可封存或已封存但尚未并入基准数据的工作区。管理员可封存符合条件的工作区，也可在需要退回修改时解封；
- **待审核批次**：显示已封存工作区的审核内容。管理员可通过 CVAT 查看或修正标注，并将批次并入基准数据；本区域不提供解封操作；
- **已有基准数据集**：显示已经并入基准数据的批次。管理员可查看、重命名、启用、停用或归档；已经并入的批次不可解封或修改。

工作区以整体为单位封存。只要业务任务下至少一个模型完成标注，工作区即可具备封存资格；其它模型即使只完成部分标注，也不阻止整个工作区封存。封存冻结整个工作区，而不是冻结某个模型或局部图片。排队中或训练中的任务存在时不封存。自动封存从最近一次完成标注或训练完成两者中较晚的时间开始计时，连续 15 天无操作后执行；管理员可以对满足标注条件且没有活动训练任务的工作区提前封存。

封存后的工作区内容仍是待审核内容，不创建重复审核快照。用户在封存期间不能操作，管理员可通过 CVAT 审核和修正。管理员解封时，工作区回到可编辑状态；管理员并入基准数据时，将已完成模型的图片和标注写入独立的基准数据批次。基准批次不保存用户、工作区或训练任务关联，也不允许回到工作区。已经并入后需要修改时，管理员先导出原始图片和标注，用户再自行新建工作区并继续现有上传流程；该导出能力不属于本阶段实现。

存量数据通过普通用户工作区导入。上传图片和已有标注可以继续复用现有标签转换与 CVAT 能力，完成相应模型标注后参与工作区封存流程。管理员页面不负责上传数据。

## Alternatives considered

**在现有普通用户页面增加管理员模式。** 该方案把工作区操作、候选审核和基准库治理混在同一入口，难以保证普通用户不能触发管理操作；独立管理员入口能让页面职责与权限边界一致。

**使用审核快照。** 快照能隔离用户修改，但会让同一工作区产生重复审核内容，并使少量标注修正需要重新复制和审核。工作区级封存提供稳定边界，同时保留一次审核期间的直接修正能力。

**在待审核区域提供解封。** 解封属于工作区生命周期控制，不属于内容审核。把解封留在工作区管理区域，避免审核页面同时承担退回、编辑和数据合并等不同职责。

**建设多用户管理员体系。** 多用户管理会引入账号创建、密码重置、禁用、身份区分和操作审计；当前单管理员、受控部署场景不需要这些能力，管理密钥足以支撑最小闭环。

**把完整基准数据集目录和编辑器都放进 CVAT。** CVAT 保留标注画布和标注修改能力；批次状态、封存、并入、重命名和启停属于平台数据管理，不交给 CVAT 的 Task/Job 目录表达。

## Acceptance criteria

- 管理员入口独立于普通用户页面，并由服务端管理密钥保护；普通用户页面不显示基准库管理入口。
- 管理员页面有工作区管理、待审核批次和已有基准数据集三个切换区域，三个区域的操作边界互不混用。
- 一个工作区只有整体封存状态；至少一个模型完成标注即可封存，未完成的其它模型不阻止封存。
- 排队中或训练中的任务阻止封存；自动封存计时从最近一次完成标注或训练完成开始，15 天无操作后触发。
- 封存期间用户不能操作，管理员能通过 CVAT 审核和修正；解封只能从工作区管理区域执行。
- 并入后的基准批次独立于用户、工作区和训练任务，支持重命名、启用、停用和归档，不能解封或修改。
- 普通用户工作区能够接纳图片和已有标注并复用现有标签转换；管理员页面不上传数据。
- 原始图片和标注导出被记录为后续能力，不新增自动创建工作区的流程。

## Risks

- 单一管理密钥不提供管理员身份区分、密码恢复或操作审计；如果部署扩展到多管理员或公网环境，需要改为账号体系。
- 封存整个工作区会暂时冻结尚未完成模型的工作；用户需要通过工作区管理区域解封后继续操作。
- 基准批次不保留来源关联，后续发现问题只能通过导出原始数据并新建工作区修正，不能直接回滚到原工作区。
- 管理员在 CVAT 中修改封存内容的权限边界需要由平台创建和分配的 Job 保证，不能只依靠前端隐藏按钮。
